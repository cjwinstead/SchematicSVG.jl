ASCII drawings

Draw the circuit as text and the parser places every symbol, wire and label:

using SchematicSVG

schem"""
            +--gnd
            |
            OA1-------+---vout
            |         |
  vin--R1---+---R2----+
"""

The schem"…" literal uses the default options. For options, call the function:

ascii_schematic(art; labels=Dict("R1" => raw"$R_1 = 10\,k\Omega$"), dx=0.5, dy=0.8, scale=50)

labels replaces any default label, dx and dy are the size of a character cell in circuit units, and other keywords are Schematic settings (xscale, border, …). elements and nodes annotate the drawing (Annotations).

Rules of thumb:

  • A word with wires on its left and right is drawn horizontally; one with wires above and below is drawn vertically.
  • A - touching a | joins it, and cells where three or more wires meet get a dot automatically, so + is only needed for corners.
  • Columns must line up exactly. Use spaces, not tabs.
  • Run op-amp input wires down to the first letter of OA1.
  • Default labels come from the names (RD → $R_D$); override any of them with labels.

Transistor stages

cs = """
                         vdd
                          |
                          RD
                          |
                          +-@d-CC2----+--out
                          |           |
  in----CC1--@g----+-----|N1          RL
                   |      |           |
                   RG     +-@s-+     gnd
                   |      |    |
                  gnd     I1   CB
                          |    |
                         vss  gnd
"""
ascii_schematic(cs)

Node tags

@name names a node without drawing a terminal. Names may contain letters, digits and _, so SPICE node numbers work (@3).

PlacementResult
--@vx-- (inline in a wire)the wire passes through; the name sits above it
---@vx / @vx--- (at a wire end)name beside the end of the wire
on the line below / above a wirename just under / over the wire
in place of a | in a vertical runthe wire passes through; the name sits to the right

Voltage marks

An O element is an open circuit that shows the voltage across it, as in small-signal models. The hybrid-π MOSFET model:

hybrid_pi = """
   g        +------+------d
            |      |
   Ovgs     G1     RO
            |      |
   s--------+------+------s
"""
ascii_schematic(hybrid_pi; labels=Dict("G1" => raw"$g_mv_{gs}$", "RO" => raw"$r_o$"))

An open circuit reaches across blank cells to the terminal or wire at each end, so g and s become its terminals with no connecting wires (a dangling wire end reached this way gets a terminal circle). The + is at the top (or left) by default; Ovgs^ and <Ovgs style markers work as for sources. Voltage marks are annotation only, and open circuits are left out of netlists.

In CircuiTikZ the same is to[open, v=$v_{gs}$], and v= on any other component draws its polarity marks beside the symbol. For placed drawings use Voltage.

Current arrows

A word starting with ~ inside a horizontal or vertical wire draws a current arrow there, so the currents branching at a node can be marked on each wire leaving it:

kcl = """
   in--~i1>--*--~i2>--R1--out
             |
            ~i3
             |
             R2
             |
            gnd
"""
ascii_schematic(kcl; labels=Dict("i2" => raw"$i_{R1}$"))

The label comes from the name (~i1 → $i_1$, ~iD → $i_D$) unless labels overrides it. Arrows point right or down by default; <~i1 points left and ~i1^ up (~i1v, down, is accepted after a digit, as for sources). The cell stays a wire, so arrows don't change the netlist.

In CircuiTikZ use i= on any to[…] (CircuiTikZ); for placed drawings use Current.

Captions

Text in double quotes is a caption, such as a title under each stage. Nothing inside the quotes is parsed, so it may contain dashes, letters and $…$ math:

two_stage = """
          vdd            vdd
           |              |
           RD             |
           |              |
           *--@x---+      |
           |       |      |
   in----|N1       +----|N2
           |              |
          gnd             *---out
                          |
                          RS
                          |
                         gnd

    "Common source"      <"Source follower"
"""
ascii_schematic(two_stage)

A caption is centred on its quotes by default. A drawn character is narrower than a grid cell, and markup like \approx takes up room in the source, so when the text should line up with something use <"text" (it starts at the opening quote) or "text"> (it ends at the closing quote). For placed drawings use Caption.
